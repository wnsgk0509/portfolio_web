# 📁 프로젝트 마크다운(.md) 작성 및 추가 가이드

이 폴더(`content/projects/`)에 새로운 `.md` 파일을 추가하면 포트폴리오 웹사이트의 **프로젝트 카드** 및 **상세보기 모달**에 자동으로 연동되어 반영됩니다.

현재 등록된 프로젝트(`Provit`, `Frade`)와 **100% 동일하게 표준화된 최신 양식**입니다. 새 프로젝트를 추가하실 때 아래 템플릿을 복사하여 작성하시면 됩니다.

---

## 📋 표준 프로젝트 마크다운 템플릿

```markdown
# 프로젝트 이름

URL: https://github.com/wnsgk0509/your-repo-name
기술: Java, Spring Boot, MyBatis, Oracle DB, React
날짜: 2026년 00월 00일 → 2026년 00월 00일
팀구성: 협업 (4명)
역할: 백엔드 API 개발 및 DB 설계, 성능 최적화

## 프로젝트 소개

**프로젝트명**에 대한 핵심 요약 및 개요를 서술합니다. 어떤 문제를 해결하기 위해 시작된 프로젝트인지, 주요 사용자 층과 비즈니스 목표를 작성합니다.

- **Backend**: Java 17, Spring Boot 3.x, MyBatis
- **Database**: Oracle DB 19c
- **Frontend**: React, TypeScript, Tailwind CSS
- **협업 & 형상관리**: Git, GitHub (Git-flow)

## 본인 역할

핵심 개발자로서 백엔드 전반의 비즈니스 로직 구현 및 데이터베이스 스키마 설계를 담당하였습니다.

- **도메인 전담 풀스택 개발**: 게시판/회원 등 주요 도메인 REST API 구축 및 비동기 화면 연동
- **DB 스키마 설계 및 쿼리 최적화**: 테이블 및 인덱스 설계, 복합 쿼리 튜닝
- **외부 연동 및 공통 모듈**: OAuth 소셜 로그인 및 파일 업로드 공통 모듈 개발
- **안정성 확보 및 리팩토링**: 동시성 이슈 제어 및 예외 처리 아키텍처 구축

## 핵심 기능

- **핵심 기능 대분류 1**:
  - 세부 기능 1: 구체적인 구현 방식 및 설명
  - 세부 기능 2: 캐싱 및 페이징 처리 방식
- **핵심 기능 대분류 2**:
  - 세부 기능 1: 비동기 처리 및 이벤트 리스너 연동
  - 세부 기능 2: 권한 검증 및 보안 필터 적용

## 트러블 슈팅 및 해결

### 1. 트러블 슈팅 핵심 문제 제목

- **문제**: 문제가 발생한 구체적인 상황 및 원인 분석 (예: 동시 요청 증가 시 데드락 발생 또는 응답 지연)
- **해결**: 문제 원인을 분석하고 적용한 구체적인 해결 로직 및 개선 성과 (예: 비동기 큐 도입 및 인덱스 적용으로 응답 속도 60% 개선)

### 2. 두 번째 트러블 슈팅 핵심 문제 제목

- **문제**: 문제 상황 및 에러 원인 설명
- **해결**: 아키텍처 리팩토링 및 검증을 통한 해결 결과
```

## 💡 각 항목별 웹사이트 화면 매핑 안내

| 마크다운 항목 | 웹사이트 표시 위치 | 설명 및 작성 팁 |
| :--- | :--- | :--- |
| **`# 제목`** | 카드 제목 & 모달 헤더 | 프로젝트의 메인 이름 |
| **`URL:`** | GitHub 바로가기 버튼 | GitHub 레포지토리 링크 (없으면 버튼 숨김 처리) |
| **`기술:`** | 기술 스택 뱃지 태그 | 쉼표(`,`)로 구분하여 기술 나열 |
| **`날짜:`** | 진행 기간 뱃지 | `2026년 00월 00일 → 2026년 00월 00일` 또는 `2025.07 ~ 2026.02` |
| **`팀구성:`** | 모달 팀 규모 정보 | `협업 (6명)` 또는 `개인 프로젝트` |
| **`역할:`** | **프로젝트 카드** 담당 역할 | 카드에 깔끔하게 들어가는 **간결한 1줄 요약** (예: `도메인 풀스택 개발 및 DB 설계`) |
| **`## 프로젝트 소개`** | 모달 프로젝트 소개 | 개요 문단 및 아키텍처 설명 |
| **`## 본인 역할`** | 모달 **🎯 담당 역할 및 상세 기여** | 상단 요약 문장 + 하단의 **불릿 리스트(`- **업무**: 세부내용`)**가 모달에 리스트로 예쁘게 분리 렌더링됨 |
| **`## 핵심 기능`** | 모달 **⚡ 핵심 기능** | 대분류(`- **대분류**:`)와 하위 들여쓰기(`  - 소분류`)로 계층 구조 자동 생성 |
| **`## 트러블 슈팅 및 해결`** | 모달 **💡 트러블 슈팅** | `### 1. 제목` 과 `- **문제**:` / `- **해결**:` 로 작성 시 하이라이트 박스로 자동 렌더링 |
| **`## 배운 점 및 회고`** | 모달 **📝 배운 점 및 회고** | 불릿 리스트 형태로 깔끔하게 렌더링 |
